# DeskDancer  v2.2.0

3D-девушки танцуют прямо на рабочем столе Windows — под музыку, в такт.
Python + PySide6 (окна) + Panda3D (3D-сцена) — без браузера: кадр с прозрачностью рисуется в окне Qt.

## Что умеет
- Девушки видны прямо в окне программы — «Предпросмотр» на странице «Сцена».
- Прозрачное окно поверх рабочего стола: двигать, менять размер, «сквозь мышь», поверх всех окон.
- До 6 девушек одновременно, у каждой своя модель, танец и рост; пресеты сцен.
- Такт из **звука ПК** (что играет в любом плеере, WASAPI loopback), **микрофона** или **вручную** (BPM + «тап»).
- Темп танца подстраивается под BPM музыки, движения попадают в долю (фазовая подстройка).
- Свои модели **GLB / GLTF** и танцы из отдельных файлов (FBX — перевести в GLB в Blender). Танцы Mixamo переносятся на скелеты
  Mixamo, Character Creator 4, Unreal/MetaHuman, Daz Genesis, VRM — кости сопоставляются сами.
- Графика: видеокарта (OpenGL / DirectX 9) или процессор — работает на любом ПК.
- Режим **«✨ Неон»**: светящийся контур фигуры и складок одежды с ореолом, как неоновое видео;
  палитры «Огонь» (золото → пурпур), «Неон», «Радуга», вспышка на каждую долю. Включается на странице «Сцена» → «Вид».

## В комплекте
10 реалистичных девушек (`characters/rocketbox/`: Алина, Вера, Дарья, Елена, Жанна, Злата, Инна, Карина, Лиза, Марина)
и 10 танцев (`dances/rocketbox/`: Весёлый, Крутой, Спокойный, Энергичный, Чувственный,
Драйв, Стильный, Ровный, Озорной, Страстный) —
из библиотеки [Microsoft Rocketbox](https://github.com/microsoft/Microsoft-Rocketbox), лицензия MIT.
Сконвертированы в GLB (текстуры 1024 px, ~3.5 МБ на девушку).

## Ещё девушки — где взять
| Источник | Что качать | Куда |
|---|---|---|
| [Mixamo](https://www.mixamo.com) (бесплатно) | Characters → женская модель → FBX Binary, **With Skin** | `characters/` |
| Mixamo | Animations → «dance» → FBX Binary, **Without Skin**, **In Place** | `dances/` |
| Character Creator 4 (Reallusion) | экспорт FBX/GLB — самые живые лица и кожа | `characters/` |
| [Sketchfab](https://sketchfab.com/search?features=downloadable+rigged&q=realistic+woman&type=models) | rigged-модели, GLB | `characters/` |
| Daz Studio (Genesis 8/9), MetaHuman | экспорт FBX | `characters/` |

Кнопка «⬇ Скачать пример» на странице «Модели» берёт тестовую модель Michelle (GLB) из репозитория three.js.

## Запуск
Двойной клик по `DeskDancer.pyw` — библиотеки (PySide6, numpy, panda3d, soundcard) поставятся сами в папку `libs/`.
Нажать **▶ Танцевать**, включить музыку.

## Python 3.15 и новее
Для Python 3.15 сборок Panda3D пока нет. Тогда 3D-движок работает в отдельном Python 3.13: программа сама
скачивает компактный Python с python.org в папку `.runtime/` и ставит туда numpy и panda3d (один раз, ~80 МБ).
Окно программы остаётся на вашем Python.

## Всё — рядом с программой
Программа ничего не ставит в системный Python: свои библиотеки — в `libs/` (pip `--target`), Python для 3D —
в `.runtime/`. Удалить программу = удалить её папку.

## Если девушек не видно
Страница «Окно» → «Графика»: «Авто» → «Процессор» (без видеокарты). В «Журнал» пишется, какая графика выбрана и сколько кадров в секунду.

## Клавиши
F5 — обновить библиотеку · Esc — стоп · Ctrl+S — сохранить · Ctrl+T — тема

## Структура
```
DeskDancer.pyw        запуск двойным кликом
deskdancer.py         ядро: такт (BPM/фаза), звук, сервер сцены, библиотека, --selftest
deskdancer_qt.py      окна: главное и прозрачная сцена
app/                  engine3d (сцена Panda3D), gltf_mesh / gltf_anim (модели и танцы), neon,
                      рамка окна, тема, обновление с GitHub (gh_update — общий модуль)
characters/, dances/  свои модели (не в репозитории)
tests/                тесты (test_deskdancer.pyw)
```

## Сборка EXE
`build_exe.bat` → `dist\DeskDancer.exe` (рядом положить `characters\` и `dances\`).
